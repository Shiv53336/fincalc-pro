# FinCalc Pro

India's smartest all-in-one financial calculator.

## Features
- 13 Financial Calculators (Tax, SIP, EMI, HRA, FD, PPF, NPS, EPF, Gratuity, GST, Salary, Lump Sum)
- Smart Tax Optimizer with personalized savings recommendations
- FY 2025-26 accurate tax calculations (New + Old Regime)
- PDF Export for Tax, SIP, and EMI reports
- Share via WhatsApp, email, or any app

## Setup
```
flutter pub get
flutter run
```

## Build for Play Store
```
flutter build appbundle
```
